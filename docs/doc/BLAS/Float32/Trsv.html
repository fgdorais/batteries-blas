    Triangular solve #

    Mat.trsv uplo diag A x solves A * y = x for a triangular matrix A, over x, by the column-oriented loops of the reference BLAS. Its specification is the recursive back-substitution model trsvLower or trsvUpper, which subtracts the terms in the order the loops do.

                              def BLAS.Float32.Mat.trsv {n : Nat} (uplo : Uplo) (d : Diag) (A : Mat n n) (x : Vec n) :
                              Vec n

                              trsv uplo d A x solves A * y = x for the triangle uplo of A, with a unit diagonal if d is .unit, by the column-oriented loops of the reference BLAS. For the lower triangle, it solves for y[j] and subtracts y[j] times column j of A from the elements below it, for j = 0, …, n - 1; for the upper triangle, it does the same from j = n - 1 down to 0, for the elements above. It updates x in place when its array is not shared, and leaves the elements of the array outside x unchanged. It reads only the triangle uplo of A, and not its diagonal when d is .unit. Like the reference BLAS, it doesn't check for a zero on the diagonal.

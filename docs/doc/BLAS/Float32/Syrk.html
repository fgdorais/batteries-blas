    Symmetric rank-k update #

    Mat.syrk uplo α A β C is α * A * Aᵀ + β * C and Mat.syrkT uplo α A β C is α * Aᵀ * A + β * C, on the triangle uplo of C, by the loops of the reference BLAS. Each element gets the operations of those loops, in the same order, with the special cases of the reference BLAS: syrk skips the terms with A[j, l] = 0, both only scale C when α = 0, and syrkT leaves C unchanged when k = 0 and β = 1.

                                    def BLAS.Float32.Mat.syrk {n k : Nat} (uplo : Uplo) (α : Float32) (A : Mat n k) (β : Float32) (C : Mat n n) :
                                    Mat n n

                                    syrk uplo α A β C is α * A * Aᵀ + β * C, on the triangle uplo of C, by the loops of the reference BLAS: for each column j, it scales the triangle's part of the column by β, or sets it to 0 without reading it when β = 0, then adds α * A[j, l] times column l of A to it, for l = 0, …, k - 1. As in the reference BLAS, it skips the terms with A[j, l] = 0, so that an infinity or a NaN in A doesn't reach them, and only scales C when α = 0. It updates C in place when its array is not shared, and leaves the elements of the array outside the triangle unchanged.

                                                    def BLAS.Float32.Mat.syrkT {n k : Nat} (uplo : Uplo) (α : Float32) (A : Mat k n) (β : Float32) (C : Mat n n) :
                                                    Mat n n

                                                    syrkT uplo α A β C is α * Aᵀ * A + β * C, on the triangle uplo of C, by the loops of the reference BLAS: for each element (i, j) of the triangle, it sums the products A[l, i] * A[l, j] for l = 0, …, k - 1 from the left, into t, then writes α * t + β * C[i, j], or α * t without reading C[i, j] when β = 0. It computes the sums of four elements of a column in each pass over column j of A, by the loops of gemvT, which gives the same sums and lets their additions overlap. As in the reference BLAS, it only scales C when α = 0, and returns C when k = 0 and β = 1. It updates C in place when its array is not shared, and leaves the elements of the array outside the triangle unchanged.

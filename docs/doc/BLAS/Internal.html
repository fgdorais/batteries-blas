    USize indices #

    The bounds of the column windows of a column-major matrix, for USize indices. They are nonlinear, so grind needs the bound X * y + X ≤ X * Y spelled out. The linear toNat facts about USize indices that don't wrap around are left to grind where they are used. These lemmas don't depend on the element type, so they live in the namespace BLAS.

    They are private: they are not part of the library's API. The files that need them use import all BLAS.Internal.

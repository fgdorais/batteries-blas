    gemm on matrices #

    Mat.gemm runs the kernel of PMat.gemmBlocked, and Mat.gemmNaive the kernel of PMat.gemm, which has the naive loops of the reference BLAS, on packed matrices. A matrix that is packed already, from the index 0 with ld = m in an array of m * n, goes to the kernel with no copy, and C is updated in place. Otherwise the matrix is packed into a copy first, and the columns of the result are copied back into the array of C, which leaves the other elements of that array unchanged. The copies take m * k + k * n + 2 * m * n steps against the 2 * m * n * k floating-point operations of the product.

                def BLAS.Float64.Mat.gemmNaive {m n k : Nat} (α : Float) (A : Mat m k) (B : Mat k n) (β : Float) (C : Mat m n) :
                Mat m n

                gemmNaive α A B β C is α * A * B + β * C, by the naive loops of the reference BLAS, over C, and gemm computes the same matrix faster. It updates C in place when C is packed and its array is not shared. It leaves the elements of C's array outside C unchanged. As in the reference BLAS, it sets C to 0 without reading it when β = 0, before adding the products, and only scales C when α = 0, without reading A or B.

                  def BLAS.Float64.Mat.gemm {m n k : Nat} (α : Float) (A : Mat m k) (B : Mat k n) (β : Float) (C : Mat m n) :
                  Mat m n

                  gemm α A B β C is α * A * B + β * C, over C, by the blocked loops of PMat.gemmBlocked. Each element gets the operations of the naive loops of the reference BLAS, in the same order, so the result is that of gemmNaive to the bit, about twice as fast. It updates C in place when C is packed and its array is not shared. It leaves the elements of C's array outside C unchanged. As in the reference BLAS, it sets C to 0 without reading it when β = 0, before adding the products, and only scales C when α = 0, without reading A or B.

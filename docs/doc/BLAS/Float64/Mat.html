    Matrices #

    Mat m n is an m × n matrix of floats, stored in column-major order in a Float64Array with an offset off and a leading dimension ld ≥ m, as in the reference BLAS: the element in row i and column j is at the index off + ld * j + i. Its shape is part of its type. Each column is a contiguous window of the array, and the other elements of the array are not part of the matrix, so a matrix can be a block of a larger one, and the routines that update a matrix leave them unchanged.

    structure BLAS.Float64.Mat (m n : Nat) :
    Type

    An m × n matrix of floats, stored in column-major order in a Float64Array, from the index off, with the leading dimension ld: column j starts at off + ld * j.

    • data : ScalarArray.Float64Array

      The array that holds the elements.

    • off : Nat

      The index of the first element.

    • ld : Nat

      The leading dimension: the distance between the starts of two consecutive columns.

    • le_ld : m ≤ self.ld

      The columns don't overlap.

    • bound : m = 0 ∨ n = 0 ∨ self.off + self.ld * (n - 1) + m ≤ self.data.size

      The last column is in the array.

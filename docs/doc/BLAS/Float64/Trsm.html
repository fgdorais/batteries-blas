    Triangular solve with several right-hand sides #

    Mat.trsm uplo d α A B solves A * X = α * B and Mat.trsmRight uplo d α A B solves X * A = α * B, for a triangular matrix A, over B, by the loops of the reference BLAS. Each element gets the operations of those loops, in the same order. As in the reference BLAS, both set B to 0 without reading A or B when α = 0, and neither checks for a zero on the diagonal.

    trsm solves each column of B by the loops of trsv, after scaling it by α, so its specification is that of trsv on the scaled column. It solves four columns at a time, which share the reads of A: the columns are independent, so each keeps the order of its operations. trsmRight updates column j of B with the columns already solved, and its specification is the recursive model trsmRightUpper or trsmRightLower.

                def BLAS.Float64.Mat.trsm {m n : Nat} (uplo : Uplo) (d : Diag) (α : Float) (A : Mat m m) (B : Mat m n) :
                Mat m n

                trsm uplo d α A B solves A * X = α * B for the triangle uplo of A, with a unit diagonal if d is .unit, over B, by the loops of the reference BLAS: for each column j of B, it scales the column by α, then solves it by the loops of trsv. It solves four columns at a time, which share the reads of A, with the same operations on each element. It updates B in place when its array is not shared, and leaves the elements of the array outside B unchanged. As in the reference BLAS, it sets B to 0 without reading A or B when α = 0, reads only the triangle uplo of A, and not its diagonal when d is .unit, and doesn't check for a zero on the diagonal.

                                def BLAS.Float64.Mat.trsmRight {m n : Nat} (uplo : Uplo) (d : Diag) (α : Float) (A : Mat n n) (B : Mat m n) :
                                Mat m n

                                trsmRight uplo d α A B solves X * A = α * B for the triangle uplo of A, with a unit diagonal if d is .unit, over B, by the loops of the reference BLAS: for the upper triangle, for each column j of B from 0 to n - 1, it scales the column by α, subtracts A[k, j] times column k for k = 0, …, j - 1, and divides it by A[j, j] unless the diagonal is unit; for the lower triangle, it does the same from j = n - 1 down to 0, with k = j + 1, …, n - 1. It updates B in place when its array is not shared, and leaves the elements of the array outside B unchanged. As in the reference BLAS, it sets B to 0 without reading A or B when α = 0, reads only the triangle uplo of A, and doesn't check for a zero on the diagonal.

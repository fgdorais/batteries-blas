    Vectors #

    Vec n is a vector of n floats, stored in a Float64Array with an offset and a stride, as in the reference BLAS: element i is at the index off + inc * i. Its size is part of its type, so the routines need no size checks. The other elements of the array are not part of the vector, so a vector can be a row or a column of a matrix, and the routines that update a vector leave them unchanged.

    source
    structure BLAS.Float64.Vec (n : Nat) :
    Type

    A vector of n floats, stored in a Float64Array from the index off, with the stride inc. The stride is positive, unless the vector has at most one element, so that its elements are at distinct indices.

    • data : ScalarArray.Float64Array

      The array that holds the elements.

    • off : Nat

      The index of the first element.

    • inc : Nat

      The distance between two consecutive elements.

    • inc_pos : 0 < self.inc ∨ n ≤ 1

      The stride is positive, unless the vector has at most one element.

    • bound : n = 0 ∨ self.off + self.inc * (n - 1) < self.data.size

      The last element is in the array.

    Level 2 #

    Matrix-vector operations: the products gemv and gemvT, and the rank-one update ger. The triangular solve trsv is in BLAS.Float64.Trsv.

    Each routine computes every element with the operations of the reference BLAS, in the same order. It runs loops over USize indices when its arrays' sizes fit in a USize, and its model otherwise, so that its specification needs no hypothesis on the size. gemv and gemvT handle four columns of A per loop, which doesn't change any element's operations.

                      def BLAS.Float64.Mat.gemv {m n : Nat} (α : Float) (A : Mat m n) (x : Vec n) (β : Float) (y : Vec m) :
                      Vec m

                      gemv α A x β y is α * A * x + β * y, with the operations of the reference BLAS, in its order for each element: it scales y by β, then adds α * x[j] times column j of A, for j = 0, …, n - 1. It adds four columns in each pass over y, which gives the same result with a quarter of the reads and writes of y. As in the reference BLAS, it returns y when n = 0, sets y to 0 without reading it when β = 0, and only scales y when α = 0, without reading A or x. It updates y in place when its array is not shared, and leaves the elements of the array outside y unchanged.

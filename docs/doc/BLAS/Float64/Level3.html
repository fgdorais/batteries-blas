    The value of gemm α A B β C at (i, j): betaMul β C[i, j], plus the terms α * B[l, j] * A[i, l] for l = 0, …, k - 1, added from the left, in the order of the reference BLAS.

        def BLAS.Float64.PMat.gemm {m n k : Nat} (α : Float) (A : PMat m k) (B : PMat k n) (β : Float) (C : PMat m n) :
        PMat m n

        gemm α A B β C is α * A * B + β * C, by the naive loops of the reference BLAS: for each column j, it scales the column of C by β, or sets it to 0 without reading it when β = 0, then adds α * B[l, j] times column l of A, for l = 0, …, k - 1. It updates C in place when C is not shared. Mat.gemmNaive handles the case α = 0, which doesn't run this kernel.

    Level 1 #

    Vector operations: the updates axpy, scal, copy and swap, and the reductions dot, asum, nrm2 and iamax.

    Each routine runs a loop over the USize indices off + inc * i of its vectors when their arrays' sizes fit in a USize, as they do for every array in memory, and its model otherwise, so that its specification needs no hypothesis on the size. The loops are the same for every stride: at stride 1 they run as fast as loops over contiguous indices.

      def BLAS.Float64.Vec.axpy {n : Nat} (α : Float) (x y : Vec n) :
      Vec n

      axpy α x y is α * x + y. As in the reference BLAS, it returns y when α = 0, without reading x, so an infinity or a NaN in x doesn't reach y. It updates y in place when its array is not shared, and leaves the elements of the array outside y unchanged.

                        nrm2 #

                        nrm2 computes the Euclidean norm by Blue's algorithm, as in the reference BLAS (dnrm2.f90, since LAPACK 3.10): it sums the squares in three accumulators, of the small elements scaled up, of the mid-range elements, and of the big elements scaled down, so that no sum overflows or underflows unless the norm itself does. The thresholds and scaling factors are powers of 2, so that scaling is exact.

                                  One step of nrm2: it adds the square of |x[i]|, scaled, to the accumulator of its range, in the sums (asml, amed, abig) of the small, mid-range and big elements.

                                  The reference BLAS stops adding to asml after the first big element. That is only a shortcut: asml is ignored once abig > 0, which holds from the first big element on, so the result is the same.

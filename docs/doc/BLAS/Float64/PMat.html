    Packed matrices #

    PMat m n is an m × n matrix of floats, packed in column-major order in a Float64Array of exactly m * n elements: the element in row i and column j is at the index i + m * j. The gemm kernels run on packed matrices; Mat m n is the general matrix, with an offset and a leading dimension, which they pack when it isn't packed already.

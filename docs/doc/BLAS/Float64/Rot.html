    Plane rotations #

    The Level 1 rotations of the reference BLAS: rot applies a plane rotation to two vectors, and rotm a modified rotation, both by zip, a loop that updates the two arrays together, in place when they are not shared. rotg and rotmg construct a rotation and a modified rotation from scalars, step for step as the reference BLAS does.

    Two vectors at once #

    source
    @[inline]
    def BLAS.Float64.Vec.zipData {n : Nat} (f g : Float → Float → Float) (x y : Vec n) :
    ScalarArray.Float64Array × ScalarArray.Float64Array

    zip f g x y writes f x[i] y[i] over x[i] and g x[i] y[i] over y[i], for each i, in place when the arrays of x and y are not shared. Both values come from the old elements. It is scalar-arrays' zipModifyStride, which checks each array once and then stores without checks.

        def BLAS.Float64.Vec.rot {n : Nat} (c s : Float) (x y : Vec n) :
        Vec n × Vec n

        rot c s x y applies the plane rotation [c s; -s c] to the pairs (x[i], y[i]), as the reference drot: x[i] ↦ c * x[i] + s * y[i] and y[i] ↦ c * y[i] - s * x[i].

          structure BLAS.Float64.RotmParam :
          Type

          The parameter of a modified rotation, the reference DPARAM array: flag is DPARAM(1) and h11, h21, h12, h22 are DPARAM(2) to DPARAM(5), the entries of H = [h11 h12; h21 h22].

          The flag tells which entries rotm reads:

          • -2: H is the identity and no entry is read;
          • -1: all four entries are read;
          • 0: h11 = h22 = 1 are implied, only h21 and h12 are read;
          • any other value (1 from rotmg, or NaN): h21 = -1 and h12 = 1 are implied, only h11 and h22 are read.
          • flag : Float
          • h11 : Float
          • h21 : Float
          • h12 : Float
          • h22 : Float

              def BLAS.Float64.Vec.rotm {n : Nat} (p : RotmParam) (x y : Vec n) :
              Vec n × Vec n

              rotm p x y applies the modified rotation H of p to the pairs (x[i], y[i]), as the reference drotm: x[i] ↦ x[i] * h11 + y[i] * h12 and y[i] ↦ x[i] * h21 + y[i] * h22, with the entries implied by the flag written out in the reference's way (see RotmParam).

                                                      source
                                                      def BLAS.Float64.rotmg (d1 d2 x1 y1 : Float) :
                                                      Rotmg

                                                      rotmg d1 d2 x1 y1 constructs the modified rotation H that zeros the second component of (√d1 * x1, √d2 * y1), step for step as the reference drotmg.

                                                      The reference writes only the entries of DPARAM that the flag says rotm reads, and leaves the others as they were; here those entries hold the values the flag implies (H is the identity for flag -2). The reference also leaves DH11 and DH22 unset on the flag 0 path, and DH21 and DH12 on the flag 1 path, until a rescaling writes them; those are not read either. Where the reference loops forever on an infinite d1 or d2, this stops after Rotmg.fuel steps.
